# v0.1 冒烟测试清单

> 范围：TXT 阅读全链路 + 书架 + 进度/书签 + 基础排版 + 极简/书卷主题 + 窗口基础功能。
> 执行方式：按下列条目逐项手动验证，通过后勾选（`[x]`）。

## 书架

- [ ] 首次启动进入书架空态提示
- [ ] 导入 TXT（链接模式）：书架出现卡片、进度 0%
- [ ] 导入 TXT（复制模式）：books/ 目录出现副本、原文件未被修改
- [ ] 直接打开文件（Ctrl+O / 拖拽）：进入阅读页并自动记入最近阅读
- [ ] 删除记录：linked 模式原文件保留；copied 模式询问是否删副本
- [ ] 搜索书架按书名过滤

## 阅读

- [ ] UTF-8 / UTF-8 BOM / UTF-16LE / UTF-16BE / GBK 文件均可正常打开不乱码
- [ ] 章节目录解析正确（默认正则），自定义正则生效
- [ ] 翻页模式：→/← 翻页、点击左右 1/3 翻页
- [ ] 滚动模式：滚轮滚动正常、→/← 翻页滚动生效
- [ ] 自动翻页：空格启停、末页自动停、翻页/滚动两种模式
- [ ] 进度：切章/翻页后返回书架再进，进度正确恢复
- [ ] 书签：Ctrl+M 添加、面板跳转、删除
- [ ] 查找：Ctrl+F 搜索、前后跳转、无结果提示
- [ ] Ctrl+G 百分比跳转
- [ ] 字体缩放 Ctrl+=/Ctrl+-

## 设置/窗口

- [ ] 主题切换（极简/书卷）即时生效并持久化
- [ ] 排版参数实时预览并持久化
- [ ] 全屏 F11、置顶 Ctrl+T、透明度 Ctrl+滚轮（数值持久化）
- [ ] 沉浸模式 F12 隐藏/恢复顶栏与边框
- [ ] 文本可选择/复制

## 异常

- [ ] 打开不存在/已移动的文件：应用不崩溃、无空白页/卡死（卡片标灰提示为后续版本）
- [ ] 删除 library.db 后应用可重建空库（书架记录丢失，书籍文件不受影响）

## 与实现的差异说明（v0.1）

- 编辑模式（Ctrl+E）已从最终阅读页移除，文本默认即可选中复制，对应清单项已调整。
- 滚动模式未绑定 ↑↓ 键，滚动速度参数（scrollSpeed）尚未接入，清单对应项已调整。
- 自定义章节正则仅在解析层支持（无界面入口），已有后端单测覆盖。
- 打开缺失文件暂未实现卡片标灰 UI，仅保证应用不崩溃。
- 窗口透明度 v0.1 仅持久化数值（Tauri 2.11 无 set_opacity 接口），整窗透明效果受平台限制。
