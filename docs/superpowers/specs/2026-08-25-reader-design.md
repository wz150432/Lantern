# 跨平台离线阅读器设计文档

> 日期：2026-08-25
> 状态：已确认（等待用户审阅）
> 参考项目：[binbyu/Reader](https://github.com/binbyu/Reader)（Win32 TXT/EPUB 阅读器，功能对标、UI 升级、去掉在线部分）

## 1. 项目背景与目标

在参考项目 binbyu/Reader 的基础上，从零开发一款**跨平台（Windows / macOS / Linux）离线阅读器**：

- **升级点**：现代化 UI（书库/书架 + 极简沉浸阅读页）、主题系统、更好的排版体验
- **移除点**：全部在线功能（在线小说搜索、书源管理、爬虫下载、章节在线更新、代理设置、联网版本更新推送）——**纯离线**
- **发布方式**：GitHub 公开发布 + 作者自用，三平台打包

## 2. 核心决策（已确认）

| 决策项 | 结论 |
|--------|------|
| 技术栈 | Tauri v2（Rust 核心 + Web 前端） |
| 前端 | Vue 3 + TypeScript + Vite（不引入通用 UI 组件库，样式手写） |
| 运行平台 | Windows / macOS / Linux |
| 联网 | 纯离线，不启用任何网络能力（构建层面保证） |
| 功能范围 | 参考项目全部本地功能，去掉在线相关 |
| 书库形态 | 书架 + 直接打开结合；导入可选"链接原文件"或"复制进书库" |
| 语言 | 仅中文，文案走资源文件、预留 i18n 结构 |
| 分发 | GitHub Releases 三平台发布 + 自用 |
| 格式 | TXT + EPUB，预留格式接口（PDF/MOBI 二期） |
| 视觉 | 默认"极简沉浸"主题，"书卷质感"等作为可选主题 |
| 快捷键 | 细节后期确认，架构上支持全量自定义 |

## 3. 功能范围

### 3.1 保留（核心阅读与设置）

**文件**
- 打开方式：Ctrl+O / 菜单打开 / 文件拖拽 / 设为系统默认打开方式（.txt/.epub）
- TXT 编码自动识别：BOM-UTF8 / UTF8 / UTF16 LE·BE / GBK / GB2312 / ANSI 等
- EPUB 解码阅读（书名/作者/封面/目录）
- 多本书切换，阅读进度独立自动保存，可删除单本阅读记录

**章节与定位**
- TXT 自动解析章节目录（树状），可跳转
- 高级设置：自定义章节解析正则（样例：`第.*章\s+.*`）
- 全文关键字查找并跳转（Ctrl+F）
- 进度百分比跳转（Ctrl+G）
- 上一章/下一章（Ctrl+←/→）

**排版（显示设置）**
- 字体（名称/字号/颜色）、章节标题字体
- 背景颜色、背景图片（支持旋转平铺）
- 字距、行距、段距、内部边框距
- 首行缩进（段首两个全角空格）、压缩空行、Word wrap
- 目录字体跟随文本
- 默认排版配置：行距 + 段距 + 首行缩进 + 压缩空行

**翻页与阅读**
- 键盘翻页（←/→）、↑/↓ 逐行滚动（速度可调）
- 鼠标滚轮翻行、左/右键点击翻页、左右 1/3 区域点击翻页
- 自动翻页（空格启停、间隔可调、翻页/滚动两种模式、翻到末页自动停）
- 编辑模式（Ctrl+E：文本复制 + 简单编辑）
- 书签：Ctrl+M 添加，列表管理，每本上限 256 个

**窗口与外观**
- 全屏（F11）、隐藏边框沉浸模式（F12）、窗口置顶（Ctrl+T）
- 窗口透明度调节（Ctrl+滚轮 / Ctrl+Shift+滚轮）
- 快速隐藏/显示窗口（Alt+H 热键、鼠标左右键同按）
- 鼠标移出窗口自动隐藏（Ctrl+Alt+Shift+P）
- 字体缩放（Ctrl+- / Ctrl+=）

**设置**
- 快捷键/热键全部可自定义
- 还原默认设置

### 3.2 去掉（在线相关，全部移除）
- 在线小说搜索、书源管理、章节下载缓存、F5 刷新在线章节
- 代理设置、联网版本更新推送

### 3.3 升级新增（UI 方向）
1. 现代化书库/书架：书籍卡片、封面缩略图、最近阅读、进度展示
2. 主题系统：极简沉浸（默认）/ 书卷质感 / 深色 / 浅色 / 护眼 + 自定义
3. 沉浸式阅读页：常驻顶栏（默认），F12 切换彻底隐藏顶栏/边框

## 4. 总体架构

### 4.1 技术选型
- 前端：Vue 3 + TypeScript + Vite，Pinia 状态管理，vue-router 三视图
- 后端：Rust（Tauri v2），命令系统作为前后端 IPC 桥梁
- 渲染策略：**Rust 管数据（解析/索引/搜索/进度），前端管渲染（排版/翻页/交互）**

### 4.2 核心组件

```
┌─────────────────────────────────────────────┐
│  前端（WebView 界面）                          │
│  ├─ 书架页 / 阅读页 / 设置页 / 目录·书签面板     │
│  └─ 排版渲染、翻页交互、主题呈现                  │
└──────────────┬──────────────────────────────┘
               │ IPC（Tauri Commands / Events）
┌──────────────▼──────────────────────────────┐
│  Rust 核心                                   │
│  ├─ 格式解析层   parsers                     │
│  │   ├─ TXT：编码检测 + 章节解析               │
│  │   ├─ EPUB：解包 + 目录 + 封面               │
│  │   └─ 统一 Book 模型 + 格式 trait（预留接口） │
│  ├─ 阅读引擎     reader                      │
│  │   └─ 章节/分页/进度/搜索                    │
│  ├─ 书库         library                     │
│  │   └─ 导入/链接、元数据、封面提取             │
│  ├─ 存储         storage                     │
│  │   └─ 设置/书架索引/进度/书签                │
│  ├─ 主题         theme                        │
│  │   └─ 主题预设 + 自定义                      │
│  └─ 窗口/快捷键   window + hotkey             │
└─────────────────────────────────────────────┘
```

### 4.3 数据流（打开一本书）
1. 前端请求 `open_book(path)`
2. Rust 检测格式 → TXT 走编码检测+章节解析 / EPUB 走解包 → 返回书籍元信息 + 章节列表
3. 前端渲染书架详情或直接进入阅读页
4. 阅读时前端按需请求章节文本 → Rust 返回 → 前端排版渲染
5. 进度/书签变化 → 前端调用 `save_progress` / `save_bookmark` → Rust 持久化

### 4.4 安全与离线
- 不启用任何网络插件，从构建层面杜绝联网
- 文件访问只通过 Rust 命令白名单（用户选择的文件 + 书库目录）
- 无遥测、无统计、无外部请求

## 5. 数据模型与存储

### 5.1 存储方案（双轨）
- **设置** → `settings.json`：主题、排版、窗口状态、快捷键映射（可手改、易备份）
- **书库数据** → SQLite（`library.db`，WAL 模式）：书架、进度、书签

### 5.2 文件位置（各系统标准应用数据目录）
```
<应用数据目录>/
├─ settings.json      # 应用设置
├─ library.db         # 书架/进度/书签
├─ books/             # 选择"复制进书库"的书籍原件
└─ covers/            # 封面缩略图缓存
```

### 5.3 核心数据表

**books（书架）**
| 字段 | 说明 |
|------|------|
| id | 主键 |
| title / author | 书名、作者（EPUB 取元数据，TXT 取文件名） |
| format | txt / epub（预留其它） |
| file_path | 文件实际路径 |
| storage_mode | `linked`（链接原文件）/ `copied`（复制进书库） |
| cover_path | 封面图 |
| added_at / last_opened_at | 加入时间 / 最近阅读时间 |
| total_chapters | 章节总数 |
| current_chapter / progress | 当前章节 + 进度（0~100%） |
| file_mtime | 文件修改时间（外部改动检测） |

**bookmarks（书签）**
| 字段 | 说明 |
|------|------|
| id / book_id | 主键 / 所属书 |
| chapter_index / position | 章节 + 书内位置（字符偏移或百分比） |
| note | 备注（可选） |
| created_at | 创建时间 |

### 5.4 关键行为约定
1. 直接打开文件：自动记入"最近阅读"，不强制进书架；可一键"加入书架"（默认链接方式）
2. 导入：可选"链接原文件"或"复制进书库"；链接方式绝不移动/修改用户原文件
3. 外部改动检测：打开时 mtime 变化则重新解析目录，进度按百分比映射
4. 删除书架条目：仅删记录/缩略图；`copied` 模式删除时询问是否一并删副本
5. 进度保存时机：翻页/切章/退出时异步写入，避免频繁 IO

## 6. 阅读引擎与排版

### 6.1 TXT 解析（重点：大文件）
- **编码自动识别**：BOM 优先（UTF-8/UTF-16 LE·BE）→ 无 BOM 用启发式检测（chardetng 等）；失败时提示手动选编码
- **分块读取**：内存映射/偏移量索引，不把整本书读进内存；扫描建"章节 → 文件偏移"索引，按需读取
- **章节解析**：内置默认规则（中文小说常见模式）+ 用户自定义正则
- **外部改动检测**：mtime 变化自动重扫，进度按百分比映射

### 6.2 EPUB 解析
- `zip` + `quick-xml` 解析 OPF/NCX/nav：书名、作者、封面、目录
- XHTML → 结构化段落文本（保留段落/标题/粗斜体基础结构，不做完整 HTML 渲染）
- v1 不支持内嵌图片/复杂样式（二期可选项）

### 6.3 统一格式接口（预留扩展）
```rust
trait BookFormat {
    fn meta(&self) -> BookMeta;                          // 书名/作者/封面/章数
    fn chapter_list(&self) -> Vec<ChapterInfo>;          // 章节标题列表（懒加载）
    fn chapter_text(&self, idx: usize) -> Result<String>; // 按需取章节文本
}
```

### 6.4 排版与分页（前端）
- 章节文本 → 段落化 → 按排版设置渲染（CSS 变量控制，实时生效）
- 翻页模式：段落流按视口高度切"页"，翻页动画，每页缓存
- 滚动模式：连续滚动 + 虚拟滚动（只渲染视口附近段落，超大章节流畅）
- 进度用"文本位置"计算（字符偏移/百分比），不依赖页数，改字号/换主题进度依然准确

### 6.5 查找（Ctrl+F）
- Rust 侧全文搜索，返回命中位置（字符偏移 + 所在章节），前端前后跳转
- 大文件搜索在 Rust 做，不把全文塞给前端

### 6.6 性能目标
- 100MB+ TXT 打开流畅、章节懒加载、翻页/滚动不卡顿
- 三层保障：章节懒加载 + 段落虚拟化 + 按需渲染

## 7. 前端界面结构

### 7.1 整体框架
单窗口 App：侧边栏导航 + 内容区，三个视图（书架/阅读/设置）+ 悬浮面板（目录、书签、查找）

### 7.2 书架页
- 顶栏：应用名、书库内搜索、`导入书籍`、`打开文件`、设置入口
- 筛选标签：`全部` / `最近阅读` / `未读完` / `书签`
- 书籍网格：封面卡片 + 书名 + 阅读进度条；排序：最近阅读/加入时间/书名
- 卡片操作（悬停/右键）：打开、加入书架、删除记录、在文件夹中显示
- 顶部"最近阅读"横条：直接打开过、未进书架的书

### 7.3 阅读页（沉浸式）
- **顶栏：默认常驻显示，不自动隐藏**；F12 切换"沉浸模式"彻底隐藏顶栏/边框（再按恢复）
- 沉浸模式下鼠标移到顶部区域临时唤起菜单
- 顶栏内容：返回书架、当前书名/章节、主题快速切换、全屏、设置
- 目录面板（左侧滑出）：章节树、高亮当前章、点击跳转
- 书签面板：书签列表、点击跳转、右键删除
- 底部进度条：百分比 + 章节位置，可拖动跳转（对应 Ctrl+G）
- 章节切换：上一章/下一章
- 查找栏（Ctrl+F）：输入 + 命中计数 + 上一个/下一个
- 点击翻页：左右 1/3 区域（模式二）或左键下一页/右键上一页（模式一），设置可切换

### 7.4 设置页（分组式）
| 分组 | 内容 |
|------|------|
| 显示 | 主题（极简/书卷/深色/浅色/护眼/自定义）、字体、字号、文字颜色、背景色/背景图 |
| 排版 | 行距、段距、首行缩进、字距、压缩空行、Word wrap、内部边距 |
| 阅读 | 翻页/滚动模式、自动翻页间隔、点击翻页模式、滚动速度、鼠标移出隐藏 |
| 窗口 | 全屏、置顶、透明度、边框隐藏 |
| 快捷键 | 全部快捷键/热键映射表，可编辑（后期细化） |
| 高级 | 章节解析正则、还原默认设置、关于 |

排版设置带实时预览区，改完立即看到效果。

### 7.5 主题系统
- 预设 5 套：极简沉浸（默认）/ 书卷质感 / 深色 / 浅色 / 护眼
- 自定义：背景色/背景图 + 文字色 + 字体（取色器用系统能力实现）
- 实现：CSS 变量 + 主题对象，切换即时生效，配置存 `settings.json`

## 8. 错误处理与边界场景

### 8.1 文件相关
| 场景 | 处理 |
|------|------|
| 打开不支持的格式 | 友好提示，支持"打开方式"对话框 |
| 编码识别失败 | 弹出编码选择列表（UTF-8/GBK/GB2312/UTF-16…），选中即重新渲染 |
| 文件被删除/移动（链接） | 卡片标灰 + "文件缺失"，提供移除记录或重新定位 |
| 文件被外部修改 | 打开时自动检测（mtime），重新解析目录，进度按百分比映射并提示 |
| EPUB 损坏/加密 | 给出具体错误信息，可继续读其它书 |
| 超大文件（100MB+） | 先建索引再进入阅读，显示轻量加载状态，不阻塞界面 |

### 8.2 数据安全
- 进度/书签/设置异步写入，崩溃最多丢最后一次写入
- 数据库损坏自动备份损坏文件、重建空库，不丢失书架里的书
- `copied` 模式删条目二次确认；`linked` 模式永不触碰原文件

### 8.3 窗口与系统边界
- 透明度/隐藏边框在 macOS/Linux 行为差异 → 功能降级不崩溃
- 全屏/置顶/热键冲突：注册失败提示，不卡死
- 多显示器、DPI 缩放自适应

### 8.4 快捷键冲突
- 映射表校验：重复绑定、与系统快捷键冲突时提示
- 全局热键注册失败时静默降级为窗口内快捷键

### 8.5 崩溃兜底
- 关键路径用 Rust `Result` 处理，前端统一错误提示
- 保留最近一次错误日志，便于作者排查用户反馈

## 9. 测试策略与三平台打包发布

### 9.1 测试策略
- **Rust 单元测试**：编码检测（全编码样本）、章节解析（默认+自定义正则、边界、100MB 大文件）、EPUB 解析（正常/损坏/缺封面/嵌套目录）、进度映射
- **前端单元测试**：排版参数→渲染、翻页切分、主题切换
- **端到端冒烟**：每平台过核心链路（导入→打开→翻页→书签→进度恢复→设置持久化）
- 采用 TDD 工作流：先写测试再实现

### 9.2 三平台打包发布（GitHub Actions）
- 推送 tag → ubuntu / macos / windows 三平台构建 release
- Windows：NSIS 安装包 + 便携版
- macOS：`.dmg`（签名公证可选，v1 先不做收费证书）
- Linux：`.deb` / `.AppImage`
- 全部上传 GitHub Releases，带中文版本说明
- 不引入自动更新（纯离线原则）；"关于"页显示版本号和源码链接

### 9.3 开发期工具链
- 本地：cargo + Node 工具链；`tauri dev` 热开发
- 规范：rustfmt + cargo clippy；前端 ESLint + Prettier
- 文档：README（功能/截图/构建指南）、CHANGELOG

### 10.2 Rust 依赖选型
| 用途 | crate |
|------|-------|
| 框架 | `tauri` v2 + 官方插件（dialog / fs / opener） |
| 编码检测 | `encoding_rs` + `chardetng` |
| 章节正则 | `regex` |
| EPUB 解包 | `zip` + `quick-xml`（或 `roxmltree`） |
| 大文件读取 | `memmap2` |
| 存储 | `rusqlite`（内置 SQLite）+ `serde`/`serde_json` |

### 10.3 前端依赖选型
- Vue 3 + TypeScript + Vite、Pinia、vue-router
- 虚拟滚动：自研轻量虚拟化（只服务阅读场景）
- 不引入通用 UI 组件库（样式手写，保证极简独特风格）
